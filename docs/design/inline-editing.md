# mardi 原地 Markdown 编辑交互设计

状态：本次实施的交互契约。日期：2026-11-03。

## 1. 目标形态

打开 Markdown 后，正文就是可以直接修改的文档。标题、强调、引用、列表和代码仍有清晰的阅读排版，用户点击一个字就能把光标放进去。窗口右上角不再出现阅读 / 编辑切换；不增加第二个预览窗格，也不出现常驻格式工具条。

采用一个连续的 CodeMirror 6 Live Preview 编辑面。原始 Markdown 是唯一内容，排版只是它的显示方式。光标附近露出必要语法，离开后回到安静的排版。切换活动行不会重新建立编辑器，不丢失撤销、选区、滚动或中文输入状态。

这是编辑 Markdown 的文档界面：既允许直接改字，也允许精确修改 `**`、链接地址、表格管道符。初版不引入独立富文本模型或 HTML 反向生成 Markdown，不在表格、代码和正文之间切换多个 contenteditable。

## 2. 参考与取舍

Typora 把阅读和写作放在同一个文档里，减少模式切换；它的官方说明也明确，光标进入行内格式时会显露源码，普通点击链接编辑、Command 点击打开。[Typora 产品说明](https://typora.io/)；[Typora Markdown Reference](https://support.typora.io/Markdown-Reference/)。

Obsidian 的 Live Preview 同样把排版结果直接显示在可编辑内容中，光标进入格式内容时露出 Markdown；它保留独立阅读模式，但 mardi 本次不需要这个额外入口。[Obsidian：Views and editing mode](https://obsidian.md/help/edit-and-read)。

mardi 采用上述共同原则，并以已有 CM6 为基础：保证文字和操作连续，复杂块进入时使用可逆的源码编辑。首版不复制 Typora 的图形表格工具条、图片管理和大量格式菜单。表格精确的单元格编辑可作为后续能力，但不能用没有源码映射的 HTML 单元格假装已经支持。

## 3. 视觉恒定

- 沿用现有 760 px 最大正文宽度、系统正文字体、浅深色配色与宽松留白。窄窗口保留至少 24 px 侧边距。
- 正文约 16 px，行高约 1.78。标题维持现有层级，H1 约 34 px、H2 约 24 px、H3 约 20 px；活动与非活动时同一块的字号、字重、行高、背景和宽度保持一致。
- 代码始终等宽。Markdown 标记用较弱的文字颜色；无需把整份文档变成彩色源码，也不保留整行蓝色的活动行底色。
- 不为语法显隐、光标移动、保存状态添加淡入或尺寸动画。直接呈现最终位置，避免输入滞后。
- 鼠标在正文是文本光标。任务框和可交互的预览具有明确反馈；只有按住链接打开修饰键时，链接才表现为跳转操作。

语法显露可能使很长的链接或表格源码换行，这是局部几何变化；正文、标题、代码的字体变化以及滚动跳到文首属于缺陷。

## 4. 光标、点击与选区

### 打开与聚焦

打开文件先展示排版，不自动改动内容、不显示未保存状态，也不把用户从文件树抢进编辑器。点击正文后获得焦点；从键盘进入正文时，初始光标放到文档开头或该文档已有的光标位置。空文件点击或键盘进入后直接出现首行光标。

### 单击与拖选

1. 单击可见文字，光标落在该文字对应的源文本位置，然后显露所属活动行的语法。不能先展开再用旧坐标重新定位，也不能每次跳到行首。
2. 单击左右空白，落在最近一行的行首 / 行末；点击最后一行以下的正文空白，落到文档末尾。侧栏、标题栏和状态栏不负责定位正文光标。
3. 双击选词、三击选行、Shift 点击扩展选区、方向键与 Shift 方向键沿用 CM6 行为。拖动越过屏幕边缘时允许编辑器原生滚动选择。
4. 非空选区涉及的行必须露出语法；涉及表格或代码块时展开整个块。选择期间不能有独立预览 DOM 抢走浏览器选区，不能因为重新排版截断原来的选择。
5. `⌘C` / `Ctrl+C` 复制原始 Markdown 选区，保留符号、缩进和换行；`⌘A` / `Ctrl+A` 选中完整文档。既有“引用 / 批注”浮层也沿用这个原文选区，触发后保留可恢复的正文选区。

复制 Markdown 的决定是首版明确契约，不做“相同选区有时复制源码、有时复制可见字”的混合规则。无需为本次加入第二种复制菜单。

### 语法显隐单位

| 内容 | 非活动时 | 活动时 |
| --- | --- | --- |
| 普通段落、标题、列表项、引用行 | 隐去可安全映射的 Markdown 标记，保留排版 | 当前源行完整可编辑；原有排版不变 |
| 强调、删除线、行内代码、链接 | 以格式文本显示 | 所在活动行显露标记 / 地址 |
| 多行代码块 | 等宽代码面，弱化围栏 | 整块源码可编辑，围栏可见，代码排版不变 |
| GFM 表格 | 排版后的表格 | 相交即整个表格源码可编辑 |
| 独立图片行 | 图像预览及简洁替代文字 | 图片源码可编辑；预览占位尽量维持稳定 |
| 未完成或未识别语法 | 原文 | 原文 |

行内格式跨越多行、嵌套结构或语法边界不确定时，显露覆盖它的完整源范围。允许多露出一点源码；不允许吞字、错误套用格式或隐藏光标所在文字。

## 5. 各类型内容

### 标题与普通段落

输入 `# ` 后形成标题排版，标题前缀在活动行仍可编辑。删除前缀即可退回普通段落。离开 / 进入标题时标题大小不变。ATX 六级标题可识别；Setext 标题保留完整语法可编辑，不为折叠下划线破坏选择。

换行遵循 Markdown 源文本：Enter 插入换行，空行分段；保留既有软换行、行末双空格和转义。不开启自动整理整份 Markdown。`**强调**`、`*斜体*`、`~~删除线~~`、行内代码具有对应的视觉格式；没有闭合的语法仍显示原文，不能阻止继续输入。

### 列表与任务

无序列表有清晰圆点，有序列表显示其编号；保留源文件的编号及缩进，不因渲染自动重写。活动行显露列表标记。Enter 延续当前列表结构；空列表项再次 Enter 退出列表。嵌套列表的相邻层级对齐，不能将列表正文的垂直方向移动映射到前缀上。

任务标记在非活动行显示为复选框。单击框只修改 `[ ]` 与 `[x]`，作为一个编辑器事务进入撤销历史，不额外插入空格、不跳动正文光标、不修改整个文档。任务完成后保持可读性，不将整行降低到难以阅读的透明度。活动行可以直接编辑标记；仅使用键盘也能完成和撤销此操作。

### 引用

非活动引用用细竖线与略弱的文字颜色；活动时 `>` 仍可见，竖线和文字基线不变化。多级引用保留层级。Enter 延续引用，空引用行再次 Enter 退出。原始 HTML 保持文字显示，不执行。

### 代码

代码内容永远在同一编辑器里可选择和修改，不把整块代码变成图片或不可选的 HTML。保持等宽字体、柔和背景、可读的语言高亮；未知语言按纯代码显示。光标进入块后可以修改开闭围栏和语言名。高亮、焦点和保存不能改变代码中的制表符、空白、反引号或换行。

初版遵循既有编辑器换行方式；如果代码自动折行，折行只是视觉行为，复制和保存不产生新换行。Tab 不成为整个应用的焦点陷阱，不为本次强行引入全局 Tab 缩进。

### 链接

普通点击只定位和编辑 `[标题](地址)`。`⌘` 点击（Windows / Linux 为 Ctrl 点击）才触发跳转；拖选链接不能打开浏览器。悬停可显示目标地址及“⌘ 点击打开”的简短提示，不增加常驻链接弹窗。

保持原有可打开协议边界：外部 http(s) 交给系统浏览器；内部锚点在文档内定位且不清除编辑历史。未支持的本地文档链接、未知协议和危险协议保留可编辑文本，不触发外部程序。自动识别的裸 URL 也遵守同样的点击规则。

### 图片

继续支持现有被授权范围内的本地位图，以及原来允许展示的图片来源。图片以正文宽度为上限，比例保持。预览不引入新的任意文件读取或图片上传能力。

点击图片，进入对应 `![替代文字](路径)` 源码；键盘上下移动也能到达源码。图片异步加载、切换活动行或修改 alt 时，不销毁 / 重建已加载图片。优先采用“源码行 / 替代文字占一行，预览在其下保持”的呈现，以避免大图在编辑时突然收缩为一行。若组件实现为源码与预览替换，必须保持该图片块已测量的占位高度和上沿滚动锚点。

加载中使用低对比占位；失败显示替代文字和“图片无法显示”，点击仍可编辑路径。不弹系统对话框、不阻断其它文字输入，不清掉源码。拖入和粘贴二进制图片不在本次扩展范围。

### 表格

非活动表格按现有排版呈现边框、标题与对齐。点击单元格后在原位置展开整块 Markdown，优先将光标定位到对应源行及单元格内容；若无法可靠计算列内映射，定位该单元格源行的最近有效位置。方向键从上下进入表格时同样展开，不能出现鼠标可编辑、键盘却跳过整个块的行为。

活动表格使用统一等宽源码视图；不承诺专用单元格 Tab 导航、行列拖拽或浮动表格工具条。选区经过表格时使用源码，不将整个表格当作一个不可拆分图片。离开后恢复表格排版。切换前后保持表格上沿 / 当前光标可见的滚动锚点，容许表格自身高度随源码变化；不能把后面的点击误映射成旧表格中的位置。

## 6. 中文输入、粘贴与撤销

组合输入从 compositionstart 到 compositionend 使用原生编辑器流程。在此期间不替换活动块、不切换 widget、不重建编辑器、不处理候选确认 Enter 为列表命令、不以 React 的滞后 value 覆盖正在输入的字符。候选框位置跟随光标。合成结束后下一次正常更新再协调语法显示；不能出现拼音重复、缺字、光标跳回或候选框消失。

粘贴以纯文本 / Markdown 为首版规则，保持中文、emoji、缩进和原始换行。来自网页的 HTML 不直接进入 DOM，也不执行脚本；有 text/plain 时使用它。粘贴、剪切、选区替换、任务切换使用 CM6 原生事务，均可撤销。大段粘贴后不滚动回文首。

`⌘Z` 撤销，`⇧⌘Z` 重做，非 macOS 沿用 CodeMirror 默认键位。语法显隐、聚焦、图片加载、保存、关闭浮层不进入撤销历史。一次任务切换一次撤销；一次粘贴一次撤销；连续文字输入沿用编辑器原生分组。自动保存后仍能撤销先前输入，并把撤销结果再次保存。

## 7. 保存、文件切换与失败

延续已有停止输入约 400 ms 自动保存和 `⌘S` / `Ctrl+S` 立即保存；顶部未保存小点与底部安静的 Saving 状态继续使用。点击、选中、语法展开不算编辑，不能触发磁盘写入或未保存标记。

自动保存不抢焦点，不替换编辑器实例，不修改滚动。快速连续输入期间，先前写入完成不能错误地把后续输入标成已保存。切换文件前继续走已有保存流程；保存失败时保留当前文档和未保存内容，错误显示于现有错误条，可以继续编辑和重试保存。

原文件被移走、删除、无写权限时保留当前缓冲区，遵循现有缺失文件处理，不悄悄写回旧路径。重命名当前文件、侧栏开关、窗口尺寸变化都不应丢失当前文档撤销历史。另一个文件打开时必须建立独立历史边界，不能一次撤销把上一份文件的内容带过来。

## 8. 长文与键盘可达性

只保留一个正文滚动容器；侧栏继续独立滚动。保持 CM6 的虚拟化能力，避免每次移动光标都渲染整份 Markdown。图片尺寸确定后缓存该显示尺寸；视口外内容变化不能把正在编辑的行推离屏幕。进入 / 离开活动语法保持当前位置，只在光标已不可见时执行必要的最小滚动。

方向键、Home / End、Page Up / Page Down、选词与跨行选区使用平台惯例。Tab 可以离开正文到应用其它控件，Shift+Tab 可返回；正文需要可见的键盘聚焦反馈和“Markdown 编辑器”可访问名称，不能只靠鼠标进入。任务源码、图片源码、表格源码都能通过键盘到达。菜单、引用 / 批注浮层关闭后焦点返回原光标位置；Escape 只关闭当前浮层，不让整个文档进入另一种模式。

选择浮层只在非空选区完成后出现，不能跟着每个字符闪现。滚动时隐藏浮层，正文继续保持选区。不将一个大段选区中每个字重新包装成 React 节点。

## 9. 空文档与降级

没有打开文件时维持现有欢迎内容 / 打开入口，不能允许编辑一段没有保存位置的假文档。打开真正的空 Markdown 后是可编辑空行，显示浅色“开始书写…”占位；输入首字占位消失，删除全部内容后再出现；占位不进入文档、不参与复制和字数统计。

解析失败或未支持结构保留原文编辑；局部预览失败不替换整篇正文为错误页。所有装饰可失效回到可用的 Markdown 文本，源内容和保存流程不依赖预览成功。

## 11. 实施参考

现有 `src/features/editor/markdown-editor.tsx` 已有 history、selection 与 Markdown parser；现有 `src/features/document/use-document-session.ts` 已有保存队列和自动保存，应复用。现有 `src/ui/markdown-preview.tsx` 是独立的只读 DOM，不能继续承担可编辑正文的选区 / 光标事实源。

CM6 官方文档规定应通过 decorations 改变文本显示，不能直接重写其内部 DOM；跨行替换或 block widget 会影响高度，必须提供合适的直接 decoration state，不能在只依赖 viewport 的插件里造成循环布局。[CodeMirror：System Guide](https://codemirror.net/docs/guide/)；[CodeMirror：Decorations example](https://codemirror.net/examples/decoration/)；[CodeMirror：Reference Manual](https://codemirror.net/docs/ref/)。具体模块与状态约束以本次架构文档为准。

## 12. 候选版本视觉核对

2026-11-03，设计师只读检查原生候选截图 `docs/testing/screenshots/candidate-1-inline.png`。该截图只能证明可见的静态排版，不能替代光标、IME、撤销与滚动验收。
